# Проект RESTstudy

## Описание
Проект разработки LMS-системы, в которой каждый желающий не может размещать
свои полезные материалы или курсы. Проект разрабатывается на Django REST framework (DRF).\
**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/AndTiho/RESTstudy.git
```
2. Установите Docker.
## Использование

## Запуск и ожидаемое поведение программы
Проект разворачивается одной командой через Docker Compose:
```
docker compose up --build
```
Программа находится на стадии разработки.

## Проверка работоспособности каждого сервиса:
### Проверка общей работоспособности:
```http://localhost:8000```.
Если открывается API — сервис работает.

### Просмотр всех контейнеров в работе:
```docker compose ps```
Если у всех Status UP, значит всё работает.

### Проверка PostgreSQL

Подключиться к контейнеру базы данных:```docker compose exec db psql -U postgres```.\
Показать список баз данных:```\l```
В списке должна присутствовать база данных проекта.

## Проверка Redis
Подключиться к Redis контейнеру:```docker compose exec redis redis-cli```\
Проверить соединение:```ping```, в ответ должно быть ```PONG```, значит Redis работает.

## Проверка Celery Worker
Проверить можно через логи:```docker compose logs celery```.\
В логах должно быть сообщение:```celery ready```, значит всё работает.

## Проверка Celery Beat
Проверить можно через логи:
```docker compose logs celery-beat```.\
Если есть сообщение ```beat: Starting...```, значит планировщик работает.
## Остановка проекта

```
docker compose down
```
