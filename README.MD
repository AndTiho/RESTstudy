# Проект EmailDjango

## Описание
Проект веб-приложения с рассылкой сообщений. \
**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
git@github.com:AndTiho/EmailDjango.git
```
2. Установите зависимости:
```
poetry install
```
## Использование
**Для запуска кастомной команды отправки рассылок используйте:**
```
python manage.py send_mailing('номер рассылки')
```
**Для запуска кастомной команды создания группы Менеджеры используйте:**
```
python manage.py create_managers_group
```
## Запуск и ожидаемое поведение программы
Для запуска проекта воспользуйтесь:
```
python manage.py runserver
```

Программа находится на стадии разработки.
